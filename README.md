# Cahier de Grammaire – French Grammar Quiz (Class IX)

A randomized multiple-choice French grammar quiz based on Section C (Q4–Q9) of the Class IX midterm model paper.

- Two levels: **Facile** and **Difficile**
- Sections: tenses, demonstrative adjectives, negation, forming questions, COD/COI pronouns, possessive adjectives
- New random questions every time, with an explanation after each answer and a review of mistakes at the end

## Host on GitHub Pages

1. Create a new public repository on GitHub (e.g. `french-grammar-quiz`).
2. Upload `index.html` (and this README) to the repository root.
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then save.
4. After a minute the quiz is live at `https://<your-username>.github.io/french-grammar-quiz/`.

It is a single self-contained file with no build step. It also works if you just open `index.html` in a browser.
